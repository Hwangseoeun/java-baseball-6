## 전체 조건
- 에러 : 사용자가 잘못된 값을 입력한 경우 ```IllegalArgumentException```


## 기능 정리
- 컴퓨터가 랜덤한 숫자 3개를 선택하는 기능
    - 조건 :
        1. 1 ~ 9 사이의 수
        2. 서로 다른 임의의 수 3개


- 사용자로부터 숫자를 입력받는 기능
    - 조건 :
        1. 1 ~ 9 사이의 수
        2. 서로 다른 임의의 수 3개


- 컴퓨터가 정한 숫자와 사용자가 입력한 숫자가 일치하는지 확인하는 기능


- 숫자가 일치하는지 결과를 출력하는 기능
    - 숫자가 모두 맞으면 게임 종료
    - 조건 :
        1. 같은 수가 같은 자리에 있으면 스트라이크 + 개수
        2. 다른 자리에 있으면 볼 + 개수
        3. 같은 수가 전혀 없으면 낫싱


- 사용자로부터 게임을 계속할건지 입력받는 기능
    - 조건 :
        1. 재시작 : 1
        2. 종료 : 2


- 게임 재시작/종료 여부 판단하는 기능


- 게임을 재시작 하는 기능


- 게임을 종료하는 기능
